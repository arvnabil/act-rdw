ANALISA ANATOMI MODUL 

Dokumen ini menjelaskan komponen-komponen file yang diperlukan untuk membuat satu modul fungsional dalam sistem modular proyek ini.

========================================================================
STRUKTUR FILE MODUL (Contoh: Modules/DynamicForm)
========================================================================

Setiap modul biasanya terdiri dari komponen berikut:

1. [ModuleName]ServiceProvider.php
   - Lokasi: Root folder modul (contoh: Modules/DynamicForm/DynamicFormServiceProvider.php)
   - Fungsi: File terpenting yang mendaftarkan konfigurasi, migrasi, views, dan resource modul ke sistem Laravel. Tanpa file ini, modul tidak akan dikenali.

2. Database/
   - Migrations/: Berisi file skema tabel database (contoh: 2026_01_03_010201_create_forms_table.php).
   - Seeders/: Berisi file untuk mengisi data awal ke database (contoh: FormSeeder.php).
   - Factories/: Berisi definisi data palsu untuk keperluan testing (contoh: FormFactory.php).

3. Models/
   - Lokasi: Modules/DynamicForm/Models/
   - Fungsi: Berisi file Eloquent Model (contoh: Form.php dan FormSubmission.php) yang menghubungkan kode dengan tabel di database.

4. Filament/
   Ini adalah folder untuk integrasi dengan Admin Panel:
   - Resources/: Definisi utama fitur di admin (contoh: FormResource.php). Di sini diatur menu apa yang muncul, siapa yang bisa akses, dll.
   - Resources/Pages/: Mengatur tampilan halaman List (daftar), Create (buat), dan Edit data (contoh: CreateForm.php, ListForms.php).
   - Resources/Schemas/: Definisi form input (contoh: FormForm.php).
   - Resources/Tables/: Definisi kolom tabel (contoh: FormsTable.php).
   - Resources/RelationManagers/: Mengatur relasi di halaman view/edit (contoh: FormSubmissionsRelationManager.php).

5. Http/Controllers/
   - Lokasi: Modules/DynamicForm/Http/Controllers/
   - Fungsi: Meng-handle request publik (contoh: PublicFormController.php).

6. Routes/
   - Lokasi: Modules/DynamicForm/Routes/
   - Fungsi: Definisi URL (contoh: web.php).

7. resources/
   - views/: File template Blade (.blade.php) untuk UI (contoh: resources/views/public/form.blade.php).

========================================================================
ALUR PEMBUATAN MODUL BARU
========================================================================

Jika Anda ingin membuat modul baru dari nol, urutan file yang biasanya dibuat adalah:

Step 1: Buat Folder Modul & ServiceProvider.
Step 2: Buat Migration di folder Database/ untuk tabel yang dibutuhkan.
Step 3: Buat Model di folder Models/ untuk akses data.
Step 4: Buat Filament Resource di folder Filament/ agar bisa dikelola lewat dashboard admin.
Step 5: Daftarkan ServiceProvider di config/app.php atau modules.json (jika menggunakan otomatisasi).

========================================================================
KESIMPULAN
========================================================================
Satu modul di dewafilament bukan hanya sekadar folder, tapi paket lengkap yang berisi database (Migration), logika data (Model), tampilan (Views), dan antarmuka admin (Filament Resource), yang semuanya diikat oleh satu ServiceProvider.
